What is this?

SmokeyFix diagnoses simple issues with Minecraft logs.

Paste in a URL to your latest log, which can be accessed from your control panel.

It is mainly aimed at my friends, but feel free to use it if you have stumbled upon it!

All processing is done locally in your browser.
